# Política de imágenes (plan B1.5)

1. Solo se publican imágenes con licencia clara: propias de Golify (capturas de la app, gráficos generados con datos propios), o licenciadas con permiso escrito para uso web.
2. Prohibido: fotos de agencias o de redes sociales sin licencia, escudos y logos como imagen principal de una nota, capturas de transmisiones.
3. Escudos y logos de equipos y ligas solo como identificación dentro de componentes de datos (los que entrega la API), nunca como ilustración editorial.
4. Cada imagen lleva `alt` descriptivo y, si aplica, `credit` visible bajo la imagen (autor y licencia).
5. Sin imagen válida, la pieza usa la imagen de marca por defecto (`/opengraph-image`); es preferible a una imagen dudosa.
6. Formato: 1200×630 mínimo para la imagen principal, WebP/JPG, ≤ 300 KB.
7. Duda de derechos = no se publica. Quien publica registra la fuente y la licencia en el PR.
